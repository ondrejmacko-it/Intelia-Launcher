# Research — first round (2026-10-19)

Targeted web research for the master plan's riskiest assumptions. Confidence: **High** = official source ·
**Medium** = several independent reports · **Low** = single report. A comment is not a consensus. Re-check before a
decision is approved. Full competitor review (Niagara, Nova, Smart Launcher, Lawnchair, Kvaesitso, Total Launcher,
Square Home, KWGT/KLWP, Key Mapper, MacroDroid, Tasker) is still open → MASTER_PLAN R0.5.

| # | Finding | Impact on Intelia | Confidence | Sources |
|---|---|---|---|---|
| F1 | Third-party launchers have no access to the Quickstep / Recents APIs; gesture navigation and app-switch animations glitch with custom launchers on many OEMs (lag, broken recents; Xiaomi disables gestures). Fixes need root (QuickSwitch Magisk module). Nova, Lawnchair and Niagara developers raised it with Google. | Never promise Recents or back-to-home animations; document it; keep Home resume fast; test Recents → Home every release. | Medium (2022–2024 reports, not re-checked on Android 16) | [GrapheneOS forum](https://discuss.grapheneos.org/d/11395-3rd-party-launchers-gesture-issues), [Fairphone forum](https://forum.fairphone.com/t/update-to-android-12-broke-switch-app-button-square/93575/23), [Android Police via Yahoo](https://tech.yahoo.com/phones/articles/third-party-android-launcher-developers-114916525.html) |
| F2 | The Nothing Phone (3) Essential Key can be remapped by third-party apps: KEA learns the key's "hardware fingerprint" during setup and offers single / double / triple / long press without a PC. Nothing announced official remapping in Nothing OS 5.1. Older workaround: disable Essential Space over ADB + Key Mapper. | Hardware Control (R7) is feasible on Nothing, but must detect the key at runtime, not by model; expect the system option to overlap — default passthrough. | Low–Medium (one KEA review; news on the OS feature) | [Beebom](https://gadgets.beebom.com/news/kea-app-made-nothing-phone-3-essential-key-useful-for-me), [Android Authority](https://www.androidauthority.com/nothing-phone-3a-essential-key-remap-3543275), [Android Authority, NOS 5.1](https://androidauthority.com/nothing-os-5-1-6-0-3707867), [Nothing Community](https://nothing.community/d/30612/99) |
| F3 | Several banking apps refuse to run while any accessibility service is enabled. | PULSE everywhere / key remap must stay opt-in with a clear warning and a one-tap off; never required for the core. | Low (community post) | [Nothing Community](https://nothing.community/d/30612/99) |
| F4 | Shizuku started through Wireless Debugging must be restarted after every reboot (official manual); ADB-started Shizuku runs as UID 2000 (shell), root-started as UID 0. External Shizuku first. | High (official manual) | [Shizuku manual](https://shizuku.rikka.app/guide/setup/), [Android Authority](https://androidauthority.com/how-to-restart-shizuku-3708818), [fork](https://upd.dev/thedjchi/Shizuku) |
